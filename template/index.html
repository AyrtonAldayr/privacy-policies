Plantilla Modular de Privacidad por Capas

Copia esta carpeta para cualquier nuevo proyecto móvil o web y activa las capas correspondientes.

Capa 1: Operación Local / Offline-First

Aplicable cuando la aplicación almacena las preferencias, registros o configuraciones del usuario únicamente en la memoria local del dispositivo sin enviarlos a servidores externos.

Capa 2: Permisos e Integraciones del Sistema Operativo

Aplicable cuando la aplicación invoca herramientas nativas del sistema (como Mapas integrados, cámara, archivos locales o navegador externo) únicamente por acción directa del usuario.

Capa 3: Servicios Backend, Autenticación y Sincronización

Aplicable cuando el proyecto habilita inicio de sesión, APIs propias sobre HTTPS/TLS o notificaciones push.

Capa 4: Derechos ARCO y Eliminación de Datos
